# Календарь

Личный календарь планов. Приложение устанавливается на телефон и компьютер, работает без интернета и синхронизирует события через Firebase.

- `index.html`: интерфейс календаря и его синхронизация через Firebase.
- `config.js`: настройки Firebase.
- `sw.js`: офлайн-режим и обновления.
- `firestore.rules`: каждый пользователь видит только свои данные.
- `vendor/`: библиотека Firebase 10.12.2 (compat).

События календаря хранятся в Firestore по пути `data/users/<uid>/calendar/items`.
