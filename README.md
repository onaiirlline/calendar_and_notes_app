# Блокнот и календарь

Личное приложение: быстрые заметки и календарь планов. Устанавливается на телефон и компьютер, работает без интернета и синхронизируется через Firebase.

- `index.html`: всё приложение (вкладки «Заметки» и «Календарь»).
- `config.js`: настройки Firebase.
- `sw.js`: офлайн-режим и обновления.
- `firestore.rules`: правило доступа, по которому каждый видит только свои данные.
- `vendor/`: библиотека Firebase 10.12.2 (compat).

Данные хранятся в Firestore по пути `data/users/<uid>/notebook/notes` и `data/users/<uid>/calendar/items`.
